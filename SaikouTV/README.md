# Kamisama

An anime and manga app for Android, owned and maintained by [nitinrawat](https://github.com/NitinRwt).

- Browse anime and manga with your AniList account
- Stream from AniWatch, HiAnime, AniWaves and AnimePahe.ng
- Liquid glass interface with light and dark themes

## Building

```
gradle assembleDebug
```

The APK is written to `app/build/outputs/apk/debug/app-debug.apk`.
